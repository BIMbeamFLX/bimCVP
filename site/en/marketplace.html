gemeinwert / marketplace

The protocol is open. The services compete.

BIM-CVP is not meant to become a single vendor marketplace. It gives providers a common signed record layer so clients can change providers without losing the file.

Provider roles.

  • Model checking and IDS validation.
  • BCF triage, coordination and issue cleanup.
  • CAM Edilizia and sustainability evidence work.
  • Building logbook generation and handover packaging.
  • openCDE adapters for existing CDE platforms.

Economic rule.

A provider can charge for hosting, review, consulting, implementation and support. The records produced by that work remain portable because the protocol, schemas and event conventions are public.

That is the Linux / Red Hat pattern applied to construction records: open core protocol, commercial competence around it, no lock-in as the business model.

First provider.

Bimbeam is the first provider profile because the protocol is grounded in real HKLS / MEP and BIM coordination work. Other providers should be able to use the same layer for architecture, structural engineering, FM, sustainability or owner advisory.
